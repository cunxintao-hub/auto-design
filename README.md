## 三个项目

### 01 · 理想汽车 UX 设计
智能座舱 / HMI 交互方向，聚焦车载界面信息层级与驾驶场景下的交互安全
**获奖：未来设计师全国三等奖**

### 02 · 高合 × 智驾系统 品牌视觉与交互升级提案
校企合作项目组长（2023.01–2023.04），含增强仪表品牌视觉传达与 ADAS 场景化模式升级两大模块
**获奖：美丽中国创新设计大赛全国二等奖**

### 03 · L4 概念车设计
面向 L4 级自动驾驶场景的概念车造型设计
**获奖：中国好创意全国三等奖**
